# Historias de Usuario - Finanz

## Épicas del proyecto Gestor de Finanzas

### Zona Pública

#### E-1: Experiencia de Primer Contacto (Landing & Marketing)
Funcionalidades para atraer y educar a visitantes potenciales

Esta épica se enfoca en crear una primera impresión impactante y proporcionar toda la información necesaria para que los visitantes entiendan el valor de Finanz, exploren sus características, comparen planes y obtengan soporte antes de registrarse. Incluye la landing page, tours interactivos, blog educativo, detalles sobre la empresa, FAQs, contacto y documentación legal.

- **HU01: Landing Page**  
  *Como visitante quiero ver la página principal con información clara y CTA, para entender rápidamente el valor de la app.*

- **HU02: Cómo funciona / Tour**  
  *Como visitante quiero un recorrido ilustrativo para aprender a usar la aplicación.*

- **HU03: Características principales**  
  *Como visitante quiero ver las funciones destacadas de la app para evaluar si me conviene usarla.*

- **HU04: Planes/Precios**  
  *Como visitante quiero comparar planes gratuitos y de pago para decidir si me registro.*

- **HU05: Blog / Artículos**  
  *Como visitante quiero acceder a contenido educativo de finanzas para aprender y confiar en la aplicación.*

- **HU06: Sobre nosotros**  
  *Como visitante quiero conocer la empresa y el equipo para sentir confianza.*

- **HU07: Preguntas frecuentes**  
  *Como visitante quiero resolver dudas rápidas sin contactar soporte.*

- **HU08: Contacto / Soporte**  
  *Como visitante quiero enviar un mensaje al soporte mediante un formulario para recibir ayuda.*

- **HU09: Política y términos**  
  *Como visitante quiero leer la documentación legal para entender mis derechos y deberes.*

#### E-2: Acceso y Autenticación
Sistema seguro de registro y acceso a la plataforma

Esta épica cubre el proceso completo de autenticación, permitiendo a los visitantes convertirse en usuarios registrados de manera segura y sencilla. Incluye formularios de registro, login, recuperación de contraseña y validaciones necesarias para proteger las cuentas.

- **HU10: Registro**  
  *Como visitante quiero registrarme en la plataforma para crear una cuenta y acceder a las funcionalidades.*

- **HU11: Login**  
  *Como usuario registrado quiero iniciar sesión para acceder a mi cuenta personal.*

- **HU12: Recuperar contraseña**  
  *Como usuario quiero recuperar mi contraseña si la olvido para poder acceder nuevamente.*

### Zona Privada

#### E-3: Finanzas Personales Básicas
Herramientas esenciales para gestionar finanzas diarias

Esta épica proporciona las funcionalidades core para que los usuarios comiencen a controlar sus finanzas inmediatamente después del registro. Incluye un dashboard resumen, registro manual de transacciones, importación automática desde archivos, gestión de cuentas y visualización en calendario.

- **HU13: Dashboard**  
  *Como usuario quiero ver un panel con mi resumen financiero para tener una visión general de mi estado actual.*

- **HU14: Registrar transacciones**  
  *Como usuario quiero añadir ingresos y egresos para llevar control de mis finanzas.*

- **HU15: Importar transacciones desde CSV/Excel**  
  *Como usuario quiero cargar mis movimientos bancarios automáticamente para ahorrar tiempo.*

- **HU16: Gestión de cuentas**  
  *Como usuario quiero crear, editar y eliminar cuentas bancarias o tarjetas para organizar mis finanzas.*

- **HU17: Calendario financiero**  
  *Como usuario quiero programar pagos y verlos en un calendario para no olvidar fechas importantes.*

#### E-4: Análisis y Control Avanzado
Funcionalidades de inteligencia y planificación financiera

Esta épica añade capas de análisis profundo y recomendaciones inteligentes para potenciar la gestión financiera. Incluye reportes visuales, definición de metas personalizadas y un agente de IA que proporciona sugerencias basadas en el comportamiento del usuario.

- **HU18: Reportes y estadísticas**  
  *Como usuario quiero visualizar gráficos interactivos de gastos e ingresos para analizar mis hábitos financieros.*

- **HU19: Metas financieras**  
  *Como usuario quiero crear metas de ahorro o inversión para motivarme a cumplirlas.*

- **HU20: Recomendaciones del Agente IA**  
  *Como usuario quiero recibir sugerencias inteligentes para mejorar mi ahorro o inversión.*

#### E-5: Perfil y Soporte en la App
Personalización y asistencia integrada

Esta épica se centra en la personalización de la experiencia del usuario y el soporte directo dentro de la aplicación. Permite gestionar perfiles, configuraciones de seguridad y acceso a guías de ayuda sin salir de la plataforma.

- **HU21: Perfil y configuración**  
  *Como usuario quiero gestionar mis datos personales, seguridad y notificaciones para personalizar la app.*

- **HU22: Centro de ayuda interno**  
  *Como usuario quiero leer guías rápidas desde la app para resolver dudas sin salir de ella.*

### Zona Administrativa

#### E-6: Administración del Sistema
Herramientas para operar y mantener la plataforma

Esta épica proporciona las funcionalidades necesarias para que los administradores gestionen la plataforma de manera eficiente y segura. Incluye paneles de control de usuarios, monitoreo de métricas del sistema y controles de seguridad para dependencias y permisos.

- **HU23: Panel de administración de usuarios**  
  *Como administrador quiero ver y gestionar usuarios, roles y accesos para mantener la seguridad.*

- **HU24: Monitoreo y métricas del sistema**  
  *Como administrador quiero revisar el uptime, logs y recursos para garantizar estabilidad.*

- **HU25: Gestión de seguridad**  
  *Como administrador quiero ejecutar controles de dependencias y permisos para reducir riesgos de seguridad.*
