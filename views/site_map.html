    • Cómo funciona / Tour
      Paso a paso visual para nuevos usuarios
    • Características principales
      Gestión cuentas, reportes, IA, calendario
    • Planes / Precios
      Gratuito vs Premium (simulado)
    • Blog / Artículos
      Contenido educativo para atraer y retener usuarios
    • Sobre nosotros
      Equipo y propósito del proyecto
    • FAQ
      Preguntas frecuentes (seguridad, exportación, cuentas)
    • Contacto / Soporte
      Formulario, correo, redes
    • Políticas (Privacidad & Términos)
      Requisitos legales y aviso de tratamiento de datos
    • Registro / Login / Recuperar contraseña
      Formularios y flujo de autenticación
  • 🔒 Zona Privada (después de login)
    Funcionalidades core para usuarios autenticados
    • Dashboard
      Resumen, KPIs, recomendaciones IA
    • Transacciones
      Crear/editar/eliminar, clasificación automática, CSV
    • Cuentas
      Agregar bancos, billeteras, ver saldos
    • Calendario Financiero
      Pagos recurrentes, recordatorios, metas
    • Reportes y Estadísticas
      Gráficas interactivas, exportación
    • Metas Financieras
      Progreso visual, planes de ahorro
    • Agente de Recomendación (IA)
      Sugerencias, perfil de riesgo, alertas
    • Perfil y Configuración
      Datos, preferencias, 2FA, eliminar cuenta
    • Centro de ayuda interno
      Soporte dentro de la app

      Usuarios, logs, roles
    • Monitoreo y métricas
      Uptime, recursos, alertas
    • Seguridad
      Dependencias, permisos, revisiones
