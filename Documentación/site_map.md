# Mapa de Sitio - Gestor de Finanzas Personales

## Descripción General
Este documento presenta el mapa de sitio del Gestor de Finanzas Personales, dividido en zonas públicas, privadas y administrativas. Incluye la estructura de navegación y funcionalidades disponibles para diferentes tipos de usuarios.

## Zona Pública (antes de login)
Páginas accesibles para usuarios no autenticados, diseñadas para atraer y convertir visitantes.

### Páginas Principales
- **Landing Page**: Hero section, beneficios, capturas de pantalla, llamada a acción (Regístrate)
- **Cómo funciona / Tour**: Guía visual paso a paso para nuevos usuarios
- **Características principales**: Gestión de cuentas, reportes, IA, calendario financiero
- **Planes / Precios**: Comparación entre plan gratuito y premium (simulado)
- **Blog / Artículos**: Contenido educativo para atraer y retener usuarios
- **Sobre nosotros**: Información del equipo y propósito del proyecto
- **FAQ**: Preguntas frecuentes sobre seguridad, exportación y cuentas
- **Contacto / Soporte**: Formulario de contacto, correo electrónico, redes sociales
- **Políticas (Privacidad & Términos)**: Requisitos legales y aviso de tratamiento de datos
- **Registro / Login / Recuperar contraseña**: Formularios y flujo de autenticación

## Zona Privada (después de login)
Funcionalidades principales disponibles para usuarios autenticados.

### Funcionalidades Core
- **Dashboard**: Resumen general, KPIs clave, recomendaciones de IA
- **Transacciones**: Crear, editar, eliminar transacciones; clasificación automática; importación CSV
- **Cuentas**: Agregar bancos, billeteras; visualización de saldos
- **Calendario Financiero**: Pagos recurrentes, recordatorios, metas financieras
- **Reportes y Estadísticas**: Gráficas interactivas, opciones de exportación
- **Metas Financieras**: Seguimiento visual del progreso, planes de ahorro
- **Agente de Recomendación (IA)**: Sugerencias personalizadas, perfil de riesgo, alertas
- **Perfil y Configuración**: Gestión de datos personales, preferencias, autenticación de dos factores, eliminación de cuenta
- **Centro de ayuda interno**: Soporte integrado en la aplicación

## Zona Administrativa (solo equipo)
Herramientas internas para operación, mantenimiento y DevOps.

### Herramientas Administrativas
- **Panel de Administración**: Gestión de usuarios, logs del sistema, roles y permisos
- **Monitoreo y métricas**: Uptime del sistema, uso de recursos, alertas automáticas
- **Seguridad**: Análisis de dependencias, gestión de permisos, revisiones de seguridad

## Notas
- Este mapa de sitio está diseñado para ser interactivo en la presentación HTML.
- Incluye controles para expandir/colapsar secciones y descargar el mapa completo.
- La estructura refleja la arquitectura de la aplicación: pública para adquisición, privada para uso diario, administrativa para mantenimiento.
