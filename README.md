# Finanz Plan

## Descripción

Finanz es un gestor de finanzas personales diseñado para ayudar a los usuarios a controlar sus ingresos, egresos y presupuestos de manera eficiente. Este proyecto incluye la planificación de la base de datos, mapa del sitio y historias de usuario para el desarrollo de la aplicación.

## Estructura del Proyecto

- `index.html`: Página principal con navegación a las secciones del proyecto.
- `views/`: Contiene las páginas secundarias.
  - `databse_plan.html`: Diagrama ERD de la base de datos.
  - `site_map.html`: Mapa interactivo del sitio web.
  - `user_stories.html`: Historias de usuario y sprints.
- `styles/`: Archivos CSS externos.
  - `base.css`: Estilos comunes.
  - Archivos específicos para cada página.
- `finanz-logo.svg`: Logo del proyecto.

## Tecnologías Utilizadas

- HTML5
- CSS3
- SVG para gráficos

## Despliegue

Este proyecto es un sitio web estático que puede desplegarse en cualquier servidor web o plataformas como GitHub Pages, Netlify, etc.
